# Task deletion policy

## When to delete

Delete a task only when it was created by mistake, is an exact duplicate, or is spam. Work that is finished should be marked completed, and work that is no longer needed should be completed with a note explaining why, so the history is preserved.

## Deletion is permanent

Deleting a task is permanent and cannot be undone. There is no recycle bin.

## Confirmation is required

Every deletion requires explicit confirmation. In the dashboard you confirm in a dialog. When you ask the assistant to delete a task, it first shows you which task it will delete and only deletes it after you press Confirm. If the task changed after the assistant asked, the assistant asks again.
