# Using the task assistant

## What the assistant can do

The assistant can list and search tasks, show a task's details, create tasks, update task fields and delete tasks. It can also answer questions about how this team works, using only this knowledge base.

## What the assistant will not do

The assistant does not answer questions that are outside this knowledge base, such as company policies that are not documented here or general knowledge like the weather. It never invents tasks, ids, dates or policies; if it cannot verify something it says so.

## Tasks created by the assistant

Tasks created through the assistant are labelled as created by the assistant in the dashboard, so the team can review them. Deletions requested through the assistant always need an explicit confirmation.
