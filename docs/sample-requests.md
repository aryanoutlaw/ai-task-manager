> through `TaskService`, confirmation flow, idempotency and the response envelope. Answer *wording* and *tool choices*
> are scripted, but every id, title, date and score in them comes from real tool/retrieval results.

response is the verbatim JSON it returned, so this file cannot drift from the real behaviour.
